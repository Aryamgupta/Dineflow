# DineFlow

DineFlow is a multi-tenant restaurant SaaS platform for QR-powered ordering, kitchen workflows, staff management, and AI-assisted operations.

## Stack

- Frontend: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL (planned)
- Cache: Redis (planned)
- Messaging: Kafka (planned)
- AI: Python/FastAPI services (planned)

## Workspace structure

- `apps/web` — customer and restaurant frontend
- `apps/api` — core API backend

## Local development

```bash
npm install
npm run dev
```

This starts the frontend and API together in development mode.
